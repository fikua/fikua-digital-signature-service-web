# Fikua Digital Signature Service · portal d'administració

Portal per gestionar els usuaris, les credencials i els certificats del [Digital Signature Service](https://github.com/fikua/fikua-digital-signature-service).

Encara no hi ha aplicació, només el prototip.

## Prototip

`prototype/index.html` s'obre amb doble clic. És un mockup: totes les dades són inventades i res no es desa.

- `console.html`: la consola, en un sol fitxer.
- `fikua.css`: els colors i la tipografia de la marca.
